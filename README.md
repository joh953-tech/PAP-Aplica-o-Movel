# PAP-Aplicação-Movél
Este projeto consiste no desenvolvimento de uma aplicação web para gestão de um ginásio, utilizando GitHub para controlo de versão e colaboração
O projeto consiste no desenvolvimento de uma aplicação móvel para um ginásio ViperGym que vai ser controlado por um sistema de gestão de base de dados centralizada as funcionalidades da aplicação vão ser Autenticação e perfil que vai ter o registo e autenticação segura para alunos e colaboradores fichas de treinos digitais com consulta interativa do plano prescrito com exercícios séries cargas tempos de descanso agendamento de aulas de grupo com cancelamento de vagas com controlo de lotação terá também um registo do processo de cada aluno com acompanhamento da evolução e do histórico de treinos e um cartao digital de acesso que gera um código QR individual para a validação da entrada na receção vou usar para isto tudo uma base de dados e um back end para o armazenamento e a sincronização dos dados.
